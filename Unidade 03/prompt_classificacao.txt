## Objetivo

Criar um experimento de classificação supervisionada capaz de prever a categoria de uma receita e comparar o desempenho das seguintes representações:
- BoW;
- TF-IDF;
- Word2Vec;
- BERTimbau.

## Regras metodológicas

Antes de implementar, analise os arquivos anexados e confirme os nomes reais das colunas. Não presuma campos que não existam.

Verifique também se há receitas associadas a mais de uma categoria.

Se houver registros multirrótulo, utilize para este experimento apenas as receitas que possuam **uma única categoria**, pois queremos seguir a abordagem multiclasse ensinada na Aula 08.

Não exclua esses registros da base original. Apenas deixe-os fora do experimento e inclua uma explicação no notebook dizendo que esses casos caracterizam um problema multilabel que poderia ser tratado futuramente.

Utilize:

- divisão de 80% para treino e 20% para teste;
- `random_state=42`;
- `stratify=y`;
- exatamente os mesmos registros de treino/teste para as quatro representações.

Evite vazamento de dados:

- BoW deve aprender o vocabulário somente no treino;
- TF-IDF deve executar `fit` somente no treino e `transform` no teste;
- Word2Vec deve ser treinado somente com os textos de treino;
- BERTimbau deve ser usado somente como gerador de embeddings, sem fine-tuning;
- a Regressão Logística deve ser treinada somente sobre os dados de treino.

Para o Word2Vec, mantenha parâmetros próximos aos já utilizados no projeto e informe palavras OOV encontradas no conjunto de teste.

Para o BERT, reutilize o modelo:

`neuralmind/bert-base-portuguese-cased`

Antes de escolher o `max_length`, analise a distribuição do número de tokens e escolha um limite adequado, respeitando o máximo do modelo.

## Avaliação

Para cada representação, apresente:

- accuracy;
- precision;
- recall;
- F1-score;
- Macro F1;
- `classification_report`;
- matriz de confusão.

Monte também uma tabela final comparando as quatro representações.

Considere o **Macro F1** uma métrica importante para avaliar o equilíbrio do desempenho entre as categorias, mas não ignore a acurácia.

Depois, identifique automaticamente o melhor resultado e mostre alguns erros de classificação contendo, pelo menos:

- título da receita;
- categoria real;
- categoria prevista.

Faça uma breve interpretação dos erros, principalmente quando houver categorias semanticamente próximas.
